Task Status (in the tasks table):

0 = Not Started
1 = In Progress
2 = Completed
3 = Blocked
Feature Status (in the features table):

0 = Not Started
1 = In Progress
2 = Completed
Subtask Status (in the subtasks table):

0 = Not Started
1 = In Progress
2 = Completed
Bug Status (in the bugs table):

0 = New
1 = In Progress
2 = Fixed
3 = Closed
Priority (in the tasks and features tables):

0 = Low
1 = Medium
2 = High
Severity (in the bugs table):

0 = Minor
1 = Major
2 = Critical
Notification Type (in the notifications table):

0 = Task Assigned
1 = Bug Reported
2 = Overdue Task
3 = Feature Updated
